### Added

- Apply database migration 0071 after deploying, from the database card on the admin overview or the banner in the mailbox. It adds the `telemetry_state` table for usage statistics; until it is applied, they stay off and [Admin → General](/general) asks for the update.
- Usage statistics, **off by default**. The owner can turn them on under [Admin → General](/general). Kite then sends one small, pseudonymous report a day, around 02:00 UTC: a random install ID made when statistics are turned on, the Kite version, Workers or Node, which modules are on, and ranges (never exact numbers) for how many accounts, active accounts and mailboxes there are and how many messages came in and went out in the last day. It never contains names, email addresses, domains, `APP_URL` or message content. The request can say more than the report: on Cloudflare Workers, Cloudflare adds a `CF-Worker` header naming your domain that Kite cannot remove, and on Node/Docker the collector sees your server's IP address; the collector reads and stores neither, though Cloudflare's own analytics may sample IP addresses. Reports go to `kite-telemetry.midego.net`, run by Michiel de Gooijer (midego) on Cloudflare on the basis of your consent; daily reports are kept 90 days, then only totals without the ID, which are public at `https://kite-telemetry.midego.net/v1/summary`. Data requests: privacy@midego.net.
- Turning statistics off deletes the install ID and asks the collector to erase that install's reports. If the collector cannot confirm it, the card shows the ID with a **Copy ID** button to send by email. Turning statistics on or off is listed under [Admin → Activity](/activity).
- Operators can set `KITE_TELEMETRY=0` to keep statistics from being turned on or sent (the owner can still turn them off), `KITE_TELEMETRY_URL` to send them to another collector, or an empty `KITE_TELEMETRY_URL` to send nothing. Nothing is sent at setup. See [Privacy](https://github.com/midego1/kite/blob/main/docs/privacy.md#usage-statistics-opt-in).

### Changed

- The privacy statement in the README and the privacy page now describe the opt-in usage statistics instead of saying Kite has no telemetry.
