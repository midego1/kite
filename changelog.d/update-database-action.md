### Changed

- Pending database updates are now the first card in [Admin settings](/admin): it lists every pending migration, says that a safety backup is saved automatically before they run (linking to [Backups](/backups)), and has a full-size **Update database** button.
- Admins other than the primary admin now see the waiting updates in Admin settings and in the mailbox notice, with the name and address of the primary admin, the only account that can apply them.
