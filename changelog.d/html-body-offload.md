### Changed

- Imported mail whose HTML body is larger than 16 KB keeps that HTML in the Mail store instead of the database, so a large import fills the database much more slowly. The message, its conversation, replies and forwards, search, the assistant, JMAP, the REST API and the mbox export read it as before; search uses the message's text, or the text of its HTML when it has no text part. Database backups carry the reference but not the HTML itself, like attachments, so back up the Mail store too. Needs migration 0074, applied from the Admin overview; until then imports keep the HTML in the database. Mail Kite receives itself is unchanged.
