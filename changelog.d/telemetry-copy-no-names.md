### Changed

- Usage statistics no longer include how many messages came in and went out (`inbound_1d` and `outbound_1d`). The report is now the Kite version, Workers or Node, which modules are on, and ranges for accounts, active accounts and mailboxes. The collector accepts reports from older installs that still send the two fields and ignores them; run its migration `0003` to drop what it stored (it is not part of the Kite app, so no Kite migration is needed).
- The usage statistics notice, the setup section and the card in [Admin → General](/general) now say what the report is for: so the Kite project can see how many active installs there are and which versions, setups and modules they run, with rough counts only and no IP addresses stored by the collector. What is sent otherwise, how often and the start date are unchanged, and they name "the Kite project" instead of a person.
- The privacy page and the deployment docs name "the Kite project" as the controller of the usage statistics collector instead of a person, and describe the same purpose. The contact address and the collector address are unchanged.
